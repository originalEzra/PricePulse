只保留三个导航，不扩大为交易平台或多微服务：

1. **行情与提醒**：首批 3–5 只真实美股，管理本人真实规则；1H/1D/1W/1M，默认 1D。1H／1D 保留真实时间比例，1W／1M 压缩日历确认的休市并显示断轴；保留准星、阈值线和实际触发标记。
2. **通知中心**：只显示 REAL 正式通知；保留已读／未读及现有提醒体验。模拟绝不进入这里。
3. **模拟行情**：本人当前真实规则的配置快照；冻结真实历史前缀＋独立模拟后缀；每用户只保留最近一次实验。仅明确开始新实验时替换旧结果，浏览其他股票不能删除结果。

模拟不开发实验历史列表、对比、导出、独立模拟规则管理或真实 MQ 投递。原来的共享 simulate/replay 写入口已关闭，不得为方便演示而重开。

用户确认的 D1–D4：

- D1：开始时冻结本人非删除规则配置；未暂停规则从 ACTIVE 初始化，包括真实 COOLDOWN/COMPLETED；PAUSED 不参与，DELETED 不复制。
- D2：下一小时是 **60 个正常交易分钟**，跳过休市／周末／节假日／提前收市，保留起点秒和纳秒以及跨收市的不足一分钟余量。
- D3：冻结起点前一个正常交易日的真实上下文、模式、幅度、seed、生成器版本及交易日历快照；播放速度可调，其他输入改变需明确新建。
- D4：启动、已确认缺口或恢复后的首笔只建新基线，不补发穿越提醒；冷却规则可按新价重新激活，但不生成触发或 Outbox。历史查询不重新执行规则。
