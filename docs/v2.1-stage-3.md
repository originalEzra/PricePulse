## 输入、时间与状态语义

- **真实历史参考**：必须选择正常交易时段最后一个已闭合分钟，且其端点等于缓存日历的 session.close。沿用服务端 pointRef／revision、真实前缀和覆盖校验；客户端不能覆盖参考价格。缺少该分钟时明确要求换用自定义模拟，不冒用更早价格作为正式收盘。
- **自定义参考**：必须使用 `SIMULATION_REFERENCE`，provider／feed 均为 SIMULATION，真实前缀为空。服务端用当前缓存中最近已闭市交易日的 close 作为模拟参考时刻，价格明确来自用户输入；不要求已有真实价格历史，但必须有可冻结的交易日历及下一开盘。
- 两种来源都冻结参考价格／时间、开盘价格／时间、UP／DOWN／FLAT 和开盘后走势。价格为正、最多四位小数；后续走势不能再次选择 OPENING_GAP。
- 开始实验只保存参考基线。首次 advance 从 close 离散前进到下一 session.open，仅提交一个点，编号 #1，价格就是所填模拟开盘价；不伪造阈值成交或休市期间成交。之后每批 60 个交易分钟，从 #2 继续。
- 日历沿用已有冻结快照，自动跳过假日、周末和提前收市后的非交易时间；后续本地日历刷新或缓存价格修订不影响已保存实验。
- 规则继续按 D1 从本人未删除正式配置冻结：未暂停规则在实验中从 ACTIVE 开始，PAUSED 不参与。直接复用纯 `RuleTransitionEngine` 的方向边界、ONCE／REPEAT、COOLDOWN 和重新激活；同点不会既重新激活又再次触发。
- 开始及推进仍复用实验行锁、expectedCurrentRunId／version／batch、Idempotency-Key 和已有隔离事务。相同开盘 Key 返回原单点批次；不同 Key 的并发旧版本请求只能成功一次。
- 开盘点对应的实验事件附带 `kind=SIMULATED_OPENING_GAP`、`scope=SIMULATION` 及冻结参考／开盘数据。实际事件 price／eventTime 保持该模拟点的价格和时间，不替换成阈值。上下文由实验参数派生，未改变正式事件表或消息格式。

## 页面与兼容

模拟模式新增“开盘跳空”，按需展示真实历史／自定义来源、参考收盘、模拟开盘、方向／幅度及后续走势。真实参考价只读，自定义明确标 SIMULATION；自定义场景不因历史价格请求失败而被禁用，日历不足仍由后端明确拒绝并保留旧实验。

图表沿用共用固定行情面板、准星、阈值线、压缩时间轴、// 断轴与虚线跳空。自定义参考以模拟颜色显示，不冒充蓝色真实历史。仅有参考／开盘两个端点时，视窗在端点外各保留一分钟，用于既有映射显示断轴；价格点和真实时间不变，未修改 `timeAxis.ts`。

模拟开盘有向上／向下／平开标识，触发 ▲／▼ 仍按规则方向绘制；点选事件与图表双向定位，详情含规则、阈值、参考价、实际模拟开盘价和纽约时间。隐藏阈值线不隐藏事件、不改变实验状态。首次操作显示“执行模拟开盘”，完成后恢复“下一交易小时”；已推进小时数不将单点开盘批次计为一小时。原串行自动播放、暂停、离页停止和恢复默认暂停继续适用。

替换旧实验采用页面内明确确认，保留原 expectedCurrentRunId、保存／覆盖及重试语义；取消确认保留原实验。确认面板不依赖浏览器原生弹窗焦点。

新前端先查询 `/api/simulations/capabilities`。旧 V8 后端返回 404 时不开放新模式，并恢复普通模式草稿；原四种模式仍可使用。新实验使用单独生成器版本，旧版本后端只能查看不支持的已保存实验，不能错误按连续分钟模式推进。
