# Phase 6A：Vue 3 Web 与端到端联调

## 目标

在不改变后端模块边界的前提下，为现有 API 增加一个可操作的 Web 界面，并验证真实业务闭环，而不是制作只展示静态假数据的页面。

## 技术选择

- Vue 3 + TypeScript + Vite：独立前端工程，快速开发并保留类型检查。
- Vue Router：登录页、行情与规则、通知中心、模拟行情四个页面。
- Pinia：管理跨页面 JWT 会话和通知角标／提示，不把所有服务端数据复制成全局状态。
- 原生 SVG：当前只需要轻量折线走势，没有引入 ECharts。
- Vite Proxy：开发环境将 `/api` 转发到 Spring Boot `18080`，不扩大后端 CORS 配置。
- 无 UI 组件库：页面规模较小，避免为少量表单和卡片引入重依赖。

## 页面能力

### 登录与注册

- 调用后端注册和登录接口。
- 本地保存 access JWT，并为受限路由增加登录守卫。
- API 返回 401 时清除失效会话并回到登录页。
- 退出时调用后端说明性接口，然后删除客户端 Token。

### 行情与提醒

- 展示演示股票、最新价格与近期有效行情。
- 价格统一显示两位小数，原始行情与计算精度保持不变。
- 原生 SVG 走势图提供价格刻度、时间刻度、十字参考线，以及悬停、点击和键盘查看。密集到同一秒的行情按序号标注，提示中保留完整事件时间。
- 按股票查看已有提醒规则。
- 选择一条图上提醒，显示当前触发价、重新激活价虚线；历史小点按持久化触发记录的 `quoteEventId` 与行情 ID 对齐，方向和阈值读取当时的规则快照。
- 创建、修改、暂停、恢复和删除规则。
- 前端提前校验重复提醒的重新激活价，但后端仍是最终校验边界。
- 金额、状态和触发方向转换为用户可读文案。

### 通知中心

- 查询全部、未读或已读通知。
- 展示不可变触发快照中的股票、价格和事件时间。
- 点击未读通知幂等标记为已读，支持全部标为已读，角标和列表同步更新。
- 登录后的所有业务页面共享未读角标，超过 99 条显示 `99+`；通知中心显示准确总数。
- 页面可见时每 5 秒查询轻量 `feed` 接口；切到后台后停止轮询，返回时立即检查，失败时退避重试，上限 30 秒。
- 新通知显示右上角页内提示，最多同时 3 个；单批超过 3 条时合并，约 6 秒自动收起，悬停或键盘聚焦时保留。
- 首次查询只建立基线，不弹历史提醒；关闭提示或点击进入通知中心不会标记已读。
- 退出、会话失效和切换账户时停止轮询并清空提示，丢弃旧账户尚未完成的响应；同源其他标签页退出时同步清理。
- 列表保留当前筛选并静默更新，当前最多展示最近 100 条；未读角标由后端全量计数，不使用列表长度估算。

### 模拟行情

- 选择股票、模式、步数、随机种子、初始价格和波动比例。
- 自动准备随机参数，并提供正常波动、上涨、下跌与震荡四种快捷模板；详细参数默认收起。
- 模拟页按百分数填写单步波动，上限为 0.3%；随机模板为 0.1%～0.3%。发送请求时换算为比例，例如 0.3% 对应 `stepRatio=0.003`。模拟 API 保留原有范围，供技术实验使用。
- 调用真实模拟接口并展示处理、重复和丢弃数量。
- 使用唯一 `runKey` 避免实验之间意外去重。
- 关联当前用户的一条提醒规则，直接查看本次完整逐点走势图，不受行情历史接口最近 100 条的限制。
- 后端在每个有效行情事务内返回该规则匹配前后的状态及真实触发 ID；图表展示上破／下破、重新激活节点和冷却区间，底部展示状态轨迹。
- 保留左侧配置、右侧结果，运行后聚焦右侧结果，不跳转页面；本次结果与之后的表单修改相互独立。
- 重复、丢弃事件不绘制为新点；没有状态转换就不生成触发标记。未关联规则时仅展示行情。

## 已验证的真实闭环

1. 浏览器登录本地测试账户。
2. 为 `DEMO001` 创建“上破 100”的一次性提醒。
3. 从 95 开始生成 10 个上涨行情事件。
4. 10 个事件全部成功处理，规则实际穿越阈值。
5. 后端在同一事务写入触发记录和 Outbox。
6. RocketMQ 消费者生成一条站内通知。
7. 通知中心展示触发价 `100.1632`，并成功标记已读。

这次验证同时覆盖了 Vue 表单、Vite 代理、JWT、规则服务、行情处理、Redis 索引、状态机、Outbox、RocketMQ 和通知查询。

## 工程边界

- JWT 使用 `localStorage` 是演示环境取舍，不宣称是所有生产系统的最佳方案。
- 页面只读取真实 API，不提供 Mock 数据模式。
- 提示属于网页内通知，页面关闭时不推送操作系统通知；邮件、短信和系统推送尚未实现。
- 当前不做复杂 K 线、真实证券行情、多渠道推送和后台管理大屏。
- AI 自然语言规则草稿属于 Phase 6B，不与基础页面一起假装完成。

```bash
cd frontend
npm run type-check
npm run build
```

后端继续使用：

```bash
./mvnw -B -ntp test
```
