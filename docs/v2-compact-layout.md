## 布局原因与调整

原固定信息区独占图表上方一行，设有 248px 高度；模拟结果卡片另受全局 515px 最小高度影响。加上独立标题、统计卡及常驻诊断说明，两页图表被推到下方。本轮实际调整组件结构与 Grid，而非只改字体或颜色。

- `frontend/src/components/PriceSparkline.vue`：共用顶部 Grid，依次放标题内容、固定概要、最新价格；标题和最新价格由两个页面通过 slot 提供。走势图紧接顶部。沿用现有时间映射、曲线分段、断轴、虚线跳空、阈值和独立事件图层。
- `frontend/src/components/ChartInfoPanel.vue`：两页共用的紧凑概要，只显示类型、纽约时间、价格和相对前一有效点的变化；模拟点按需显示编号。桌面宽度最多 280px，内容自然撑高，本轮实测 113px；没有独立整行或覆盖曲线的大浮层。
- `frontend/src/views/DashboardView.vue`：股票名称、代码、四个范围按钮和必要行情状态在左，固定概要在中间，最新价格在右。取消大统计卡，完整规则表放在图表下方全宽区域。连接、延迟、历史缺口及正式提醒开关仍准确提示；点数、缓存区间、来源详情和安全错误移入折叠的“行情详情”。
- `frontend/src/views/SimulationView.vue`：实验配置使用紧凑字段 Grid，Seed 收入高级选项；最近实验改用起点、当前行情、交易时长与两项紧凑规则指标，取消 515px 最小高度。图表顶部采用同一组件结构；原价、偏移、原始时间及详细快照按需展开。模拟规则与事件表在桌面并排，窄屏自动上下排列。

无悬停、无固定选中时概要显示最新有效点。普通悬停只更新概要、准星、高亮点及轴标签，不改变顶部尺寸。点击触发标记才在图下显示事件详情，完整规则快照另可展开。关闭详情恢复最新概要，并清除关联的事件行高亮。

## 规则与事件

模拟规则表与真实规则表复用 `frontend/src/styles/ruleTable.css`，主表精简为显示、规则、方向、阈值、状态、本次结果六列；来源、版本、一次性／重复及重新激活价放入快照详情。没有单规则下拉框，也不能在模拟表修改正式规则。

首次默认显示最多三条 ACTIVE／COOLDOWN；COMPLETED 默认隐藏、允许手动选择。颜色按来源真实规则 ID 确定，表格与阈值线保持一致。勾选只影响展示，触发事实和快照状态不变。

本实验事件改成内部最多 280px 高的滚动表，保留触发及重新激活，方向有图标和颜色。事件行支持点击／Enter 定位实际图表时间和价格；图中聚合标记能同时高亮对应多行，自动显示第 100 条之后的匹配事件。详情仅在选择时展开，不再为每条事件生成大卡片。

使用既有只读事件分页完整统计本次规则结果，避免只读第一页而把后续才触发的规则显示为“未触发”；分页水位变化或游标重复时明确失败，不伪造结果。DOM 表格仍分批展示。此适配没有修改 API、模拟计算或历史记录。

其他展示工具：`frontend/src/utils/chartInspection.ts` 保留纳秒时间对应关系、寻找前一个有效价并格式化简短纽约时间；`utils/simulationDisplay.ts` 处理只读事件分页和触发次数；`utils/ruleDisplay.ts` 生成快照阈值线；`utils/chart.ts` 补充事件展示所需元数据。
