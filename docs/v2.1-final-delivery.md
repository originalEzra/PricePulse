## 回滚边界与剩余事项

原 [加载计划](v2.1-rollout-plan.md) 的分时点回滚仍有效：不得盲目删 V9／V10、回放 V8 SQL 覆盖运行库或用旧 V8 二进制处理新的取消／订阅语义。一旦有新需求、取消、模拟或自然行情事实，优先向前修复；必要恢复须先到另一个空库验证并保留失败库。Redis 仅按 token 重建，不清空共享实例。

保留外部待验：

1. **IEX 主动关闭 1006**：既有供应商专项失败仍有效，新进程未出现错误不等于修复；本轮不为验证关闭而中断正常监控。
2. **自然正式开盘跳空**：没有满足连续性与价格条件的真实事件就标未验；模拟与专项集成通过不能替代自然行情。
3. **第十六股及更高额度／实际动态增删**：目前 15／15，三个账户都需要原十五股；不擅自取消他人需求、提高预算或开第二连接。加载初始集合的实际确认，不等于供应商完整动态增删场景已验。
4. **持续运行边界**：本机须保持后端、Vite、中间件、网络与机器唤醒；短时间验收不构成全天 SLA，Mac 休眠可能导致重建基线和漏过未知穿越。
